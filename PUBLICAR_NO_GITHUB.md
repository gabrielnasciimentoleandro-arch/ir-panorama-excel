## Publicação pelo navegador

1. Acesse `https://github.com/new` estando conectado à conta correta.
2. Em **Repository name**, digite `ir-panorama-excel`.
3. Cole a descrição informada acima.
4. Selecione **Public**.
5. Não marque a criação automática de README, `.gitignore` ou licença, pois eles já existem no projeto.
6. Clique em **Create repository**.
7. Na página vazia, escolha **uploading an existing file**.
8. Envie o conteúdo desta pasta, preservando as pastas `docs` e `scripts`.
9. Use a mensagem de commit:

   `feat: adiciona organizador autoral IR Panorama`

10. Confirme o commit na branch `main`.

## Arquivos que devem aparecer

- `ir_panorama_organizador.xlsx`
- `README.md`
- `PUBLICAR_NO_GITHUB.md`
- `LICENSE`
- `requirements.txt`
- `.gitattributes`
- `.gitignore`
- pasta `docs`
- pasta `scripts`

Se o navegador não mostrar os arquivos iniciados por ponto, eles podem ser criados posteriormente pelo botão **Add file → Create new file**. Eles melhoram o repositório, mas a planilha, o README, as imagens e os scripts são os itens principais da entrega.

## Conferência após publicar

- o repositório está público;
- o README aparece na página inicial;
- as duas imagens carregam;
- o arquivo Excel pode ser baixado;
- as pastas `docs` e `scripts` estão presentes;
- a licença MIT foi reconhecida;
- nenhum arquivo com dados pessoais foi enviado.

## Entrega na DIO

**Descrição:**

IR Panorama é um organizador autoral desenvolvido em Excel para centralizar dados e documentos usados na preparação da declaração de Imposto de Renda. A solução reúne cadastro do titular e dependentes, rendimentos, bens, pagamentos, informes e notas em dez abas integradas por um menu de navegação. O painel apresenta totais, progresso documental e pendências; as tabelas utilizam filtros, listas de validação, cálculos automáticos e formatação condicional. O projeto funciona localmente, sem macros, APIs ou serviços pagos, e o arquivo público utiliza somente dados fictícios para preservar a privacidade.
