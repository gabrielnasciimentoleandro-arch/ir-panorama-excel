# Segurança e privacidade

Dados de declaração de Imposto de Renda são altamente sensíveis. Este projeto foi preparado para publicação somente porque utiliza informações fictícias.

## Regras para uso pessoal

1. Baixe a planilha e salve uma cópia fora da pasta do repositório.
2. Dê um nome terminado em `_pessoal.xlsx`; esse padrão está bloqueado pela `.gitignore`.
3. Apague os exemplos antes de inserir dados reais.
4. Não envie a cópia real para GitHub, fóruns, chats ou pastas públicas.
5. Não publique capturas contendo CPF, endereço, renda, patrimônio, recibos ou nomes de arquivos pessoais.
6. Proteja o computador com senha ou biometria.
7. Prefira backup criptografado ou mídia mantida em local seguro.
8. Revise o endereço de qualquer site antes de informar credenciais.
9. Transmita a declaração somente pelos canais oficiais.

## Limites da ferramenta

- não calcula o imposto devido;
- não valida regras fiscais específicas;
- não transmite declaração;
- não acessa conta Gov.br;
- não acessa bancos ou corretoras;
- não envia dados para servidor;
- não possui macro;
- não exige API ou assinatura.

## Em caso de incidente

Se uma cópia com dados reais for publicada por engano, remova o arquivo imediatamente, trate o histórico do repositório como potencialmente exposto e altere credenciais que tenham sido incluídas. Para situações graves, procure suporte especializado.
